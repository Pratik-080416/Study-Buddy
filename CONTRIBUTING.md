# Contributing to Study Buddy

Thanks for helping! This project is Hacktoberfest-friendly.

1. Fork the repo and create a branch: `git checkout -b my-change`
2. Make your change and test it with `streamlit run streamlit_app.py`
3. Open a pull request describing what you changed and why

Good first contributions: new "explain it" styles, UI tweaks, bug fixes,
docs, and testing tiny models (gemma3:1b, llama3.2:1b, qwen2.5:0.5b).
Look for issues labeled `good first issue`.
